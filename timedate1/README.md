# systemi-timedate1

`systemi-timedate1` is a portable implementation of [org.freedesktop.timedate1](https://www.freedesktop.org/software/systemd/man/latest/org.freedesktop.timedate1.html) targeting the BSDs, specifically FreeBSD. My goal to develop small daemons that implement interfaces used by desktop environments so that users of the BSDs and non-systemd Linux have a comparable experience with systemd Linux.
